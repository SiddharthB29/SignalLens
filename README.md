# SignalLens

**AI-Assisted Incident Intelligence Platform**

SignalLens is a backend engineering project designed to ingest application error events, group related errors into incidents, and support evidence-based incident investigation.

## Planned Features

- Event ingestion and validation using Spring Boot
- Asynchronous event processing using Apache Kafka
- Incident correlation and deduplication
- Incident management APIs
- PostgreSQL persistence and Redis caching
- AI-assisted investigation using Spring AI and RAG
- Observability using OpenTelemetry, Prometheus, and Grafana
- Automated testing and containerized deployment

## Technology Stack

- Java and Spring Boot
- Spring Security and Spring Cloud Gateway
- Apache Kafka
- PostgreSQL and Redis
- React and TypeScript
- Docker Compose
- JUnit 5, Mockito, and Testcontainers
